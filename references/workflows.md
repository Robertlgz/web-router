# 平台与研究工作流

本文件属于网络能力统一路由公开版 3.0.0。所有工具均为可选能力，未随本包提供。执行前加载当前实际安装件的说明，核验其操作系统支持、调用参数、授权和费用；名称相近不代表接口一致。

## 1. 可选能力映射

| 能力 | 候选示例 | 接入条件与降级 |
|---|---|---|
| 多引擎搜索 | multi-search-engine | 已安装且可调用；否则使用宿主搜索 |
| 语义搜索 | Exa 或其他语义服务 | 已授权、预算已确认；否则关键词交叉检索 |
| 中文新闻 | tencent-news 或已连接新闻工具 | 按当前授权说明使用；否则读取可信公开页面 |
| 学术论文 | arxiv-watcher 或其他学术查询工具 | 确认可查询字段；否则访问论文索引公开页面 |
| 公众号搜索 | wechat-article-search 或已有公众号工具 | 确认当前渠道与权限；否则公开收录搜索 |
| B站字幕 | bilibili-subtitle、bilibili-summary 等相关技能 | 以会话实际名称为准，不能假定两者可互换；缺失则请用户提供字幕 |
| 视频字幕获取 | yt-dlp 或已有平台字幕工具 | 核对当前版本、授权与可用字幕轨；不能保证任意视频可取 |
| 音频转写 | 已有本地或云端转写工具 | 云端上传前确认数据范围和费用；不重复安装模型 |
| 受控浏览器 | agent-browser、browser-use 或宿主浏览器能力 | 核验当前平台支持和会话权限，不沿用旧版本兼容性结论 |
| 网页渲染提取 | Scrapling 或其他已有渲染工具 | 仅限获准访问的页面，不用于绕过访问控制 |
| 平台结构化采集 | 官方接口或经审查的采集工具 | 遵守平台规则、范围与限额；有绕过限制的要求则不调用 |
| 仓库检索 | GitHub 连接器、gh 或仓库阅读工具 | 只使用已授权能力；公开资料可走网页阅读 |
| 深度研究 | deep-research 或已有研究工作流 | 在目标、时间范围和来源覆盖明确后执行 |
| 技能发现 | 宿主推荐市场、SkillHub、find-skills | 核实渠道真实可用性；不推定不同渠道的 ID 可互用 |

没有任何单个第三方工具是本技能的强制依赖。不提供默认密钥、免费额度承诺、固定版本、代理端口或可复制执行的占位命令。

## 2. 公众号内容筛选

1. 根据主题、日期与来源要求获取候选文章；保留标题、账号、链接、发布时间和实际获取到的字段。
2. 去重并粗筛，再读取最相关候选全文。默认先验证少量样本，深读首批不超过十篇。
3. 需要传播表现排名时，优先使用真实、可验证的互动数据，并标注采集时间。
4. 没有阅读数等字段时，可按选题相关度、信息增量、结构清晰度给出明确标注的编辑推荐分；不得称其为真实热度、阅读排名或爆款指数。
5. 最终输出筛选依据、推荐理由、原链接及未获取项。

## 3. 中文社交平台、新闻与热榜

- 先区分关键词搜索、热搜词榜、作品榜、作者作品列表和评论采样，避免混用统计口径。
- 采用当前可用的官方或合规授权渠道。未经验证的聚合端点只作待评估候选，不凭历史记录断言其免费或有效。
- 仅需要筛选内容时优先获取元数据；不自动下载视频、图片或整批评论。
- 有互动字段时保留原名称、数值、统计时间；跨平台指标不可直接当成同一量纲比较。
- 遇到登录限制时走正常授权或请用户提供导出数据；不通过改变请求身份、签名或会话材料规避限制。
- 新闻与天气等时效信息注明查询时间和目标地区，区分事件发生时间、发布时间与网页更新时间。

## 4. B站、YouTube 及其他视频平台

### 搜索与筛选

先按主题获取候选，再按标题、作者、时长、语言、发布日期和实际可得的互动字段筛选。不将某平台的历史失败经验推广为所有视频永久不可获取。

### 字幕与全文

1. 检查当前视频是否存在用户有权获取的字幕或转写入口。
2. 字幕为空时区分权限限制、接口失败、无字幕和工具未支持；不要据匿名空结果直接判定无字幕。
3. 核对实际字幕轨的语言、来源以及是否为翻译；英文逐字稿必须来自英文字幕或英文音频转写，不能把中文机翻反译后称作原文。
4. 优先已有字幕；需要音频转写时先确认访问权、上传目的地和费用。不为只要文本的任务默认下载整段视频。
5. 只有标题、简介或搜索摘要时，输出“基于简介的概述”，不声称已完整观看。

### 文本整理的两条输出路线

- 逐字稿：按语义补标点，谨慎修正同音误识别，保留原意；不确定内容标记“听辨不清”或“待核对”，不得悄悄删去关键段落或补造事实。
- 摘要：按内容结构概括，保留重要限制和不同观点。只有真实字幕或转写带时间码时才提供时间戳；引语须可回溯原文。

### 批量与收藏夹

先确认用户指定的清单或收藏夹范围，再分页读取、去重与筛选。首批不超过十条，验证成功后按需要继续；不默认获取全部账户收藏。按内容 ID 缓存结果时仅存任务所需数据，不缓存授权材料。

## 5. 视频号分享内容

1. 尝试读取分享页实际可见的标题、作者、日期和描述；无法获取时如实说明。
2. 区分“基于描述概述”“全文总结”“字幕转写”和“下载文件”，模糊时询问目标。
3. 使用当前已有、受支持的授权工具执行对应分支；不附带私有接口地址、临时播放令牌或会话提取配方。
4. 若需把链接提交给第三方总结服务，先确认用户允许该服务接收链接与内容。私有分享链接可能含访问权限，不默认外传。
5. 文件下载仅限用户具有相应权限且平台允许的方式。通过实际播放与元数据核对完整性，不以固定时长阈值判定完整或预览。
6. 关键词搜索缺失时可检索其他平台上的同主题内容，但必须标注“替代来源”，不能说已搜遍视频号或已找到原片。

## 6. X、Reddit 与其他社交数据

先核实当前可用的授权接口或公开页面，不把历史第三方 API 路径、匿名额度与速率上限写成固定契约。按发现候选、主题筛选、帖子或线程深读、多源对照的流程进行。

只报告实际获取的内容和互动字段，保留原链接与查询时间。缺失私信、编辑历史或分页数据时说明边界；搜索结果不可被称为平台全量讨论。

## 7. 技能与工具生态检索

### 先查已有

先看当前会话技能清单，再按必要性检查宿主明确的技能安装位置。已有能力足够时直接使用，不为检索任务新增安装。

### 多源覆盖

全面调研可按六类渠道建立覆盖表：

1. 宿主生态：已安装套件、推荐市场，以及可用的 SkillHub 渠道。
2. 独立技能搜索生态，例如当前可用的 find-skills 渠道。
3. 开源代码仓库。
4. 公众号文章。
5. 图文社区，例如小红书。
6. 视频社区，例如抖音。

六类来源相互补充。简单找技能可优先检索最相关渠道；全面调研应逐类记录“已检索、无结果、缺权限或当前不可用”，不假装完成缺失来源。缺权限不触发自动安装、登录或扩大采集。

### 候选评价与安装边界

- 保留来源、名称、版本、用途、依赖、费用条件和当前验证状态。
- 区分市场宣传、文档声明和实际文件审查证据。
- 不同市场的名称、标识与包内容需分别核对，不能直接互换。
- 用户要求安装时，先检查实际技能正文和全部附带脚本、资源；不能只审宣传页。
- 下载包不执行；拒绝越界解包、未知启动项、凭证外传和不必要的系统修改。
- 费用、授权或来源无法核实时明确标注，未经用户确认不选择收费路径。

## 8. 开源工具适配性核查

1. 核实仓库身份和当前分支。访问失败时区分权限、网络、改名、迁移与删除，不仅依据一次状态码定论。
2. 查看许可证、维护时间、版本与平台支持；实时指标必须实查并注明时间，不照搬旧星数。
3. 对关键行为阅读源码：复制还是链接，是否覆盖已有文件，冲突时是否备份，目标目录如何确定，是否启动服务或上传数据。
4. 对照用户当前需求与授权范围评估影响，不读取无关配置或其他账号资料。
5. 给出“新增能力、迁移成本、安全边界、未核验项”，不把机制相似直接当成值得替换。

下载只读源码副本时不运行安装脚本、不降低解包安全过滤。审查链接时区分符号链接、Windows junction 和普通目录；具体删除或同步语义必须核到相关函数，不能仅凭名称推断。

## 9. 浏览器与周期编排

浏览器操作遵循“读取当前状态、执行一个必要动作、核对结果”的循环。验证码与登录由用户通过正常页面完成；操作完成后按宿主约定释放本次创建的资源，不关闭用户原有会话。

用户要求周期执行时，仅使用宿主提供的自动化接口；创建前查重，指令必须自包含但不得含凭证。区分一次性执行成功与未来排程已创建，不用本次成功推断未来每次都可用。

## 10. 故障判断速查

| 观测 | 可行的下一步 | 禁止的推断或动作 |
|---|---|---|
| 搜索零结果 | 调整关键词、核对登录与索引覆盖 | 宣称内容不存在 |
| URL 返回 404 | 核对地址、权限、重定向及来源状态 | 仅凭一次响应认定已删除 |
| 认证或权限失败 | 正常授权、用户提供导出文件 | 提取其他客户端会话绕过 |
| 页面正文为空 | 核对是否需渲染，再尝试授权浏览器 | 将简介当全文 |
| 命令找不到 | 核对已安装运行时与工具位置 | 猜路径、全局安装整套依赖 |
| 字幕轨语言不符 | 切换实际存在的正确语言轨 | 用翻译稿冒充原文 |
| 网络或服务超时 | 检查可达性，有限重试并记录 | 自动更改系统代理或无限重试 |
| 触发限额或风控 | 停止当前分支，说明限制 | 换身份、绕验证或扩大并发 |

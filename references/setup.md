# 首次配置向导

本指南由 Agent 在首次使用、用户要求配置或关键能力缺失时按需加载。配置必须基于使用者自己的设备，不包含作者环境预设。普通查询已有足够工具时无需先完成全部配置。

## 1. 确定最小需求

先询问或从上下文确认：
- 使用什么客户端和操作系统？
- 只要普通搜索与网页阅读，还是需要特定平台、字幕、语义检索或浏览器？
- 是否已有服务账号或可用连接器？是否接受新增付费服务？

一次只问当前任务必需的问题。未明确费用授权时不启用收费路径。

## 2. 只读能力盘点

优先查看会话工具、已安装技能清单与宿主提供的连接状态。需要 CLI 时核对操作系统、实际安装位置、受管运行时版本与官方支持范围；不要全盘搜索私人目录，也不要读取密钥值。

输出简表：能力、现有工具、可用/缺失/未授权、最小下一步。缺失能力只记录状态，不删除通用路由表。

## 3. 网络与代理

1. 用当前任务的一个公开页面做小流量可达性检查，记录真实错误，先区分 DNS、TLS、服务超时与身份验证失败。
2. 网络正常则不配置代理。确需代理时询问用户已有代理的协议、地址、端口与使用范围；这些值不得猜测，也不提交公共仓库。
3. 先读取客户端或工具对应版本的官方代理说明。区分宿主联网工具、浏览器和本地 CLI：给 shell 设置变量不保证其他组件也走代理。
4. 优先单次进程或客户端专属设置，说明修改范围和恢复方式，用户确认后实施；不改全局系统代理，不关闭 TLS 校验，不安装根证书，不暴露监听端口。
5. HTTP、HTTPS 与 SOCKS 支持以实际工具文档为准，不套用统一命令。涉及代理认证时使用宿主安全凭证入口，不把含口令的地址输出到日志。
6. 配置后重测同一页面；失败如实报告，不通过绕访问控制解决。

## 4. API 与连接器

1. 先复用已连接、满足目标的服务；缺失才推荐最小可选项。
2. 核对提供方官方文档中的服务地址、参数、额度、计费与授权范围。兼容 API 不代表功能、模型或配额相同。
3. 优先使用宿主连接器授权或系统凭证存储。不要让用户在公开 Issue、README 或聊天中贴出密钥；没有安全配置通道时由用户自行在官方设置页填写。
4. 解释数据流：搜索词、页面内容或音频会发送给谁，是否收费；敏感资料外传必须单独确认。
5. 改本地配置前按宿主规则备份并合并新项，不覆盖现有连接器或打印凭证。仅请求必需权限。
6. 用一个低成本、非敏感请求验证；仅报告成功/失败、状态码和必要错误摘要，不显示密钥或签名链接。

## 5. 程序与运行时依赖

- 优先已有运行时、工具和技能；不默认安装全部示例工具。
- 根据官方文档核对版本与系统兼容性；安装前审查实际技能和脚本，说明下载来源、体积、权限与安装位置，取得用户确认。
- Python 使用独立虚拟环境；Node 使用项目或受管环境，不全局安装；以实际确认路径调用，不猜解释器路径。
- 浏览器依赖可能需要额外下载，先说明磁盘与内存要求；不修改用户现有浏览器会话或读取其凭证缓存。
- 不直接执行下载内容或仓库启动脚本；版本和来源审查通过后才按宿主安全流程运行必要安装步骤。
- 配置失败时不自动提权、禁用安全工具或修改系统环境；保留可用基础能力并解释缺口。

## 6. 验收与本地状态

按已配置能力逐项小样本验证：普通搜索给官方来源；网页读取核对真实正文；字幕核对语言；API 检查响应字段；浏览器只打开公开页，不提交表单。

区分“配置已写入”“工具调用成功”“宿主已发现技能”和“整个工作流验证通过”。普通模型恰好调用搜索不能单独证明技能自动触发；需要宿主加载记录或显式加载证据。

默认在对话中提供配置结果和剩余项。用户要求持久化时，只在技能目录和仓库之外的私有位置保存非敏感状态（能力、版本、验证日期、配置项是否存在），不得保存密钥、Cookie、口令或私人文件原文；若需要实际路径，明确它属于本机私有记录，不加入开源产物。后续执行仍核对当前状态，不能把历史可用当作永久可用。

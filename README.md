# web-router · 网络能力统一路由

一个面向 AI Agent（WorkBuddy 等技能型宿主）的**网络能力路由技能**：当用户提出联网搜索、网页提取、平台内容查询、视频字幕整理或浏览器自动化需求时，本技能帮助 Agent 在 L0–L5 六类能力之间选择正确的路径，并提供降级、安全与证据纪律。

## 这是什么

技能本体是两个 Markdown 文件（无代码、无脚本、无外部依赖）：

```
web-router/
├── SKILL.md                  # 路由决策表 + 执行/降级/安全规则
└── references/
    └── workflows.md          # 平台细分工作流（公众号/社交平台/视频/仓库核查等）
```

- **L0** 基础搜索 · **L1** 网页正文提取 · **L2** 语义检索 · **L3** 平台专用工具 · **L4** 周期编排 · **L5** 浏览器交互
- 核心设计原则：**标签用于分类，不代表必须逐层执行**；先看目标，再选最轻的可用工具。

## 安装

1. 下载本仓库（Code → Download ZIP，或 `git clone`）。
2. 将 `web-router/` 文件夹放入你的 AI 客户端技能目录：
   - WorkBuddy 用户级：`~/.workbuddy/skills/web-router/`
   - WorkBuddy 项目级：`<工作区>/.workbuddy/skills/web-router/`
   - 其他客户端（Claude Code、Cursor 等）：放入对应技能/规则目录即可，本技能为纯 Markdown，无宿主专有调用。
3. 新开会话即可触发。触发词示例：`网络检索`、`联网搜索`、`爬虫`、`浏览器自动化`、`web_search_stack`。

## 配置指南（按你自己的环境）

本技能**不捆绑任何工具**。安装后请根据你的环境做一次对账，把 SKILL.md 的路由表落成"你真正有"的能力清单：

### 第 0 层：宿主基础能力（多数人开箱即有）

- **搜索**（L0）：确认你的客户端有 WebSearch 类工具。
- **读网页**（L1）：确认有 WebFetch / web-reader 类工具。
- 两者都没有？本技能仍可指导"多来源交叉核查"的方法，但联网验证类任务无法执行——请向你的客户端确认联网权限。

### L2 语义检索（可选）

- 有 Exa / Tavily / 智谱等语义搜索账号？在 mcporter 或 MCP 配置中接入，路由表会自动命中"语义搜索"分支。
- 没有？降级链是"关键词组合 + 多源交叉检索"，不装也能用。

### L3 平台工具（按需安装）

| 平台 | 能力 | 示例工具 |
|---|---|---|
| B站 | 字幕全文、时间戳定位 | bilibili-summary、yt-dlp |
| YouTube | 字幕、播放列表 | yt-dlp（需代理时自行配置） |
| 微信公众号 | 文章搜索 | wechat-article-search 类技能 |
| 小红书/抖音 | 搜索、元数据采集 | MediaCrawler 等开源采集器 |
| GitHub | 仓库检索、源码审查 | gh CLI、GitHub MCP |
| 学术 | 论文检索 | arxiv-watcher 类脚本 |

> 以上均为**示例候选**，不是本技能的依赖。装不装、装哪个，取决于你的合规要求与账号情况。**未安装时请删除或注释对应决策表行**，避免 Agent 试图调用不存在的工具。

### L4 周期任务（可选）

- WorkBuddy 用户：使用官方 automation（`automation_update` 工具）。
- 其他客户端：用 cron / Windows 任务计划 / GitHub Actions 等任意调度器，把 SKILL.md 作为提示词模板周期执行。

### L5 浏览器自动化（可选）

- agent-browser、browser-use、Playwright MCP 等均可。
- **安全提醒**：不要把浏览器调试端口暴露到局域网/公网；验证码和登录请人工完成。

### 网络环境（按需）

- 若你的网络需要代理访问部分站点，请在**宿主客户端**的代理设置或环境变量中配置；本技能不预设任何端口、地址或代理规则。
- 中国大陆用户访问 GitHub/海外学术源可能需要代理；纯国内平台（B站、公众号、小红书等）通常无需代理。

### 验证安装

新会话中说一句："**联网查一下 X 的官方文档，给出处**"——若 Agent 先调用搜索工具、再读取正文并标注来源，说明路由已生效。

## 设计理念

1. **先问"有没有"，再问"好不好"**：安装前先盘会话内已有技能与连接器，避免重复建设。
2. **降级链显式化**：每个首选工具都标注"缺失时怎么办"，杜绝静默失败。
3. **证据纪律**：区分"读完全文 / 只看摘要 / 仅凭简介推断"；未登录 ≠ 内容不存在；404 ≠ 永久删除。
4. **安全边界**：不解密浏览器凭证、不提取其他客户端会话、不自动绕验证码/付费墙、不执行仓库脚本。
